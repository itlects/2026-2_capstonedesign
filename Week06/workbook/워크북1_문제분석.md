# 워크북1 — 문제 정의·근본원인 분석

## 학습성과
5주차 실패 시험을 재검토하고 사실과 가설을 구분하여 검증 가능한 개선 문제를 정의한다.

1. 5주차 시험표에서 실패/지연 건을 하나 고른다.
2. 해당 FR/WBS/Issue ID 및 증빙 링크를 기록한다.
3. 기대 결과와 실제 결과를 수치 또는 관찰로 구분하여 작성한다.
4. '왜?'를 반복하여 가능한 원인을 추적하되, 원인이라고 확정하지 않는다.
5. 원인 가설 2개 이상을 세우고 가설별 재현 조건·시험 방법·판정 기준을 작성한다.
6. 교차검토자가 '사실인가 가설인가?' 피드백하고 수정한다.
