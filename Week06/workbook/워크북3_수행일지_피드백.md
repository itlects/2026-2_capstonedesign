# 워크북3 — 개인 수행일지·동료 피드백·7주차 PBL

1. 오늘 맡은 WBS ID와 실시한 작업을 실제 수행 시간 순서로 기록한다.
2. 완료 작업은 테스트 결과와 증빙 URL을 제시한다. 미실행 활동은 '계획'으로 기록한다.
3. 동료에게 성과 근거의 적절성에 대한 피드백을 받고, 관찰/의견/개선 요청을 분리한다.
4. 수용 여부, 결정 이유, 다시 시험할 항목을 적는다.
5. 7주차 개인 PBL을 Facts / Ideas / Learning Issues / Action Plan으로 1건 작성한다.

## 자기 점검
- [ ] 팀 결과와 개인 기여를 구분했다.
- [ ] 실패한 시험을 삭제하지 않고 원인 가설로 연결했다.
- [ ] 계획에는 담당자, 기한, 합격 기준이 있다.
- [ ] 개인정보·API 키를 제거했다.
