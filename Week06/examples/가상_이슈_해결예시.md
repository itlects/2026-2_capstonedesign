# 가상 사례 — 센서 측정값 전송 지연

**이 사례의 숫자는 설명용 가정값이며 실제 학생 측정치가 아닙니다.**

- 요구사항 FR-02: 센서 데이터를 서버에서 확인할 수 있어야 함.
- 관찰 Facts(가정): 시험 10회 가운데 서버 수신 실패 3회.
- 가설1: 무선 신호 세기 변화로 인한 패킷 손실.
- 가설2: 연결 종료 후 재연결 처리 부족.
- Learning Issue: RSSI 기록, 전송 재시도 조건, 연결 로그 구조 확인.
- 대안 A: 전송 재시도 추가. 대안 B: 재연결 상태머신 도입.
- 결정 예시: 1차로 오류 재현 로그 확보 후 가설을 검증하고, 재시도 로직을 실험한다.
- 수용 기준 예시: 동일 조건 20회 반복 시 수신 실패 0회, 원본 로그 보존. 수용 기준은 실제 프로젝트 요구에 따라 조정.
- 개인 일지에는 코드 수정자, 시험자, 증빙 URL을 각각 명시한다.
