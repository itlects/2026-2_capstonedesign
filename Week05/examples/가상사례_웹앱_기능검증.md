# 가상 예시: 회원 검색 기능 검증
> 교육용 가상 시나리오로, 실제 학생 실험 결과가 아닙니다.

- FR-01: 회원명으로 목록을 검색한다.
- W05-01: 검색 필드·입력검증·조회 동작을 구현한다.
- TC-01 정상: '김' 입력→이름에 김이 포함된 결과만 표시.
- TC-02 오류: 공백 입력→정책대로 전체 목록 또는 안내 표시.
- TC-03 경계: 존재하지 않는 문자열→오류 없이 빈 결과/안내 표시.

## 근거 확보 방법
1. 각 시험 직전에 입력값을 기록한다.
2. UI 전후 화면 및 로그를 캡처한다.
3. `test_cases.csv`에 실제 결과를 직접 적는다.
4. 실패 시 Facts/Ideas/Action Plan을 갱신한다.

## 포트폴리오 문장 예
'본인은 회원 검색 화면과 입력 처리를 담당하였다. 정상·오류·경계조건 시험 3건을 설계하였고, 실제 결과 및 수정 이력을 테스트표와 커밋으로 기록하였다.'
