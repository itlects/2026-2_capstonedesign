# 워크북2 개인 PBL·DU 포트폴리오

1. 본인 담당 WBS를 한 건 이상 선택한다.
2. templates/personal_pbl.md 파일을 복사하여 Problem→Facts→Ideas/Learning→Action→Result→Reflection 순서로 채운다.
3. 각 단계에 실제 증빙 URL/측정값을 넣고, 확정한 사실과 가설을 구별한다.
4. 개인 기여를 팀 전체 기여와 혼동하지 않는다.
5. DU 포트폴리오 매뉴얼을 참고해 직무역량과 성찰을 보완한다.
6. 개인정보·암호·API 키 노출 여부를 점검한다.

제출: 개인 PBL, 증빙 링크, 전후 개선내용, 차주 목표.
