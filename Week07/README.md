# Week07 — 프로젝트 진행 현황 점검 · 개인 PBL 심화

강의계획서 7주차: **팀프로젝트 진행 상황 및 개인 PBL 작성, 포트폴리오 자료 작성**
→ 8주차 **직무역량평가 1차(35%) · 핵심역량평가 1차(5%)** 의 근거 자료가 됩니다.

## 학습 목표
1. 요구사항(FR) → WBS → 시험(TC) → 증빙을 한 줄로 연결해 진행 현황을 설명한다.
2. 6주차 Action Plan의 이행 결과를 증빙으로 확인한다.
3. 담당 업무를 PBL(Problem → Facts → Ideas/Learning → Action → Result → Reflection)로 기록하고 DU 포트폴리오에 반영한다.
4. 발표·교차 피드백으로 협업능력 · 현장실무 이해 · 자원관리 이해를 행동 근거로 보인다.

## 공통 규칙
| 항목 | 규칙 |
|---|---|
| 상태값 | **미착수 · 진행중 · 검증완료 · 차단 · 미확인** (이 5개만 사용) |
| 검증완료 | 팀이 합의한 완료 기준(DoD)을 모두 충족하고 **열리는 증빙 URL**이 있을 때만 |
| 진척률 | 가중 진척률 = Σ(가중치 × 검증된 완료율) ÷ Σ가중치. 증빙 URL이 없으면 완료율 0으로 계산 |
| 위험 점수 | 가능성(1~5) × 영향(1~5). 15↑ 높음 · 8~14 중간 · 7↓ 낮음 |
| 피드백 조치 | **수용 · 보류(이유 필수) · 추가확인** |
| 발표 순서 | ① 문제·목표 ② FR별 진행 현황·가중 진척률 ③ 시연/대체 증빙 ④ 6주차 Action Plan 결과 ⑤ 팀원별 기여 ⑥ 위험·8주차 계획 (5~7분) |
| 구분 표기 | 추측은 (가설), 안 한 일은 (계획), 증빙 없는 결과는 (미확인) |
| 보안 | API 키 · 비밀번호 · 개인정보 · 학번을 공개 저장소와 캡처에 넣지 않음 |
